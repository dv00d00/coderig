# Triage labels

| Matt Pocock role | CodeRig label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer must evaluate the card |
| `needs-info` | `needs-info` | Waiting for information or a product decision |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation or external access |
| `wontfix` | `wontfix` | Will not be actioned |

Store the selected role as `**Triage:** <label>` near the top of the backlog card. Lifecycle remains represented by the card's directory and is independent from triage.
